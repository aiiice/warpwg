===============================================
  Warp 无感换号网关 v2.0.7 - 快速开始
===============================================

欢迎使用！本项目已改为嵌入式 Python 部署方案
无需安装 Python，开箱即用！

===============================================
  第一次使用？按这个顺序操作
===============================================

步骤 1: 配置 Python 环境（自动）⭐
----------------------------------------
双击运行:
   setup-python-env.bat

等待几分钟，脚本会自动:
- 检查系统 Python
- 复制到项目目录
- 安装 mitmproxy
- 验证环境

提示：如果系统没有 Python，请先安装:
https://www.python.org/downloads/
（安装时勾选 "Add Python to PATH"）


步骤 2: 验证环境（可选）
----------------------------------------
双击运行:
   check-python.bat

检查是否通过所有测试项


步骤 3: 安装依赖
----------------------------------------
打开命令提示符:
   cd electron-app
   npm install


步骤 4: 启动应用
----------------------------------------
开发模式:
   npm start

或打包后双击 exe 文件


步骤 5: 配置证书
----------------------------------------
在应用中:
1. 进入"网关"页面
2. 点击"生成证书"按钮
3. 等待生成完成
4. 点击"安装证书到系统"按钮
5. 确认安装成功（显示绿色✅）


步骤 6: 启动网关
----------------------------------------
1. 点击"启动"按钮
2. 等待启动成功
3. 开始使用！

===============================================
  已经配置过？直接启动
===============================================

如果之前配置过环境，现在只需:

1. 验证环境（可选）:
   check-python.bat

2. 启动应用:
   cd electron-app
   npm start

3. 或双击打包后的 exe 文件

===============================================
  重要提示
===============================================

⚠️ 本项目使用嵌入式 Python
   - 不依赖系统 Python
   - Python 环境在 resources/python-embed/
   - 必须先配置环境才能使用

⚠️ 首次使用必须配置证书
   - 生成证书（运行 mitmdump）
   - 安装到系统（受信任的根证书颁发机构）
   - 验证安装（检查证书管理器）

⚠️ 网关启动需要 Warp IDE
   - 自动检测 Warp 路径
   - 或在设置中手动配置

===============================================
  目录结构说明
===============================================

项目根目录/
├── electron-app/           # Electron 应用
│   ├── main.js            # 主进程
│   ├── app.js             # 渲染进程
│   └── package.json       # 依赖配置
├── backend/               # Python 后端
│   └── gateway/
│       └── warp_gateway_pro.py
├── resources/             # 资源文件
│   └── python-embed/      # ⭐ Python 环境
│       ├── python.exe
│       └── Scripts/
│           └── mitmdump.exe
├── data/                  # 用户数据
├── logs/                  # 运行日志
├── setup-python-env.bat   # 自动配置脚本
├── check-python.bat       # 环境检查脚本
└── 快速开始.txt           # 本文件

===============================================
  常用命令
===============================================

# 配置环境
setup-python-env.bat

# 检查环境
check-python.bat

# 安装依赖
cd electron-app && npm install

# 启动应用（开发模式）
cd electron-app && npm start

# 打包应用
cd electron-app && npm run build

# 测试 Python
resources\python-embed\python.exe --version

# 测试 mitmdump
resources\python-embed\Scripts\mitmdump.exe --version
